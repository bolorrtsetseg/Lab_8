
# NomNom – Хоол захиалга, хүргэлтийн систем

## Төслийн танилцуулга
NomNom нь Монгол хоолны газрын онлайн захиалга,
хүргэлтийн веб систем юм.

## Үндсэн боломжууд
- Хэрэглэгч бүртгүүлэх, нэвтрэх
- Хоолны цэс харах
- Сагсанд хоол нэмэх
- Захиалга үүсгэх
- Захиалгын төлөв харах
- Админ, хоолны газрын ажилтан, хүргэлтийн ажилтны удирдлага

## Ашигласан технологи
- Python
- Flask
- SQLite
- HTML, CSS, JavaScript

## Систем ажиллуулах заавар

### 1. Репозитор татах
git clone https://github.com/bolorrtsetseg/NomNom-Web.git

### 2. Төслийн хавтас руу орох
cd NomNom-Web

### 3. Python орчин үүсгэх
python3 -m venv .venv

### 4. Орчныг идэвхжүүлэх (macOS)
source .venv/bin/activate

### 5. Сангуудыг суулгах
python -m pip install -r requirements.txt

### 6. Веб ажиллуулах
python app.py

### 7. Browser дээр нээх
http://127.0.0.1:5001

## Өгөгдлийн сан
SQLite өгөгдлийн сан ашиглана.
Өгөгдлийн сангийн файлыг GitHub-д байршуулахгүй.
Аппликейшний эхлүүлэх код өгөгдлийн санг
автоматаар үүсгэдэг бол анх ажиллуулахад үүснэ.
